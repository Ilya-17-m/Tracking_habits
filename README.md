# 🤖 Habit Tracker Telegram Bot

Telegram-бот для отслеживания привычек, разработанный на **FastAPI**.

Проект позволяет создавать привычки, управлять ими и получать автоматические напоминания в Telegram. Backend построен по принципам REST API и поддерживает мониторинг, логирование и централизованную обработку ошибок.

---

# 🚀 Возможности

- 🤖 Telegram-бот
- 👤 Регистрация и авторизация пользователей
- 🔐 Безопасная аутентификация
- ➕ Создание привычек
- ✏️ Редактирование привычек
- 🗑️ Удаление привычек
- ✅ Отметка выполнения привычек
- ⏰ Автоматические напоминания
- 📊 Мониторинг приложения
- 📝 Централизованное логирование
- 📖 Swagger и ReDoc документация API
- 🧪 Покрытие проекта тестами

# 🚀 Начало работы

## Требования

Перед запуском необходимо установить:

- Python 3.12+
- Docker
- Docker Compose
- Poetry

---

## Установка зависимостей

Установите Poetry:

```bash
pip install poetry
```

Установите зависимости проекта:

```bash
poetry install
```

---

## Настройка переменных окружения

Создайте файл

```
.env
```

и заполните его необходимыми переменными окружения.

---

## Запуск проекта

Самый простой способ запуска:

```bash
docker compose up --build
```

Docker автоматически создаст и запустит необходимые контейнеры.
